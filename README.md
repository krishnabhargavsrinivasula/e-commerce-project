# 🛍️ E-Commerce Website

A modern and responsive e-commerce website built using **HTML, CSS, and JavaScript**. The project provides a smooth shopping experience with product browsing, search, filtering, wishlist, shopping cart, and checkout features.

## 🚀 Features

* 🏠 Responsive homepage
* 👕 Men, Women, Kids & Sports categories
* 🔍 Product search
* 🏷️ Product filtering and sorting
* ❤️ Wishlist functionality
* 🛒 Shopping cart with quantity controls
* 👀 Quick product view
* 💳 Demo checkout form
* 🌙 Dark mode
* 📱 Fully responsive design
* 🔔 Toast notifications
* 💾 Local Storage support for cart and wishlist

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, animations and responsive design
* **JavaScript** – Interactivity and functionality
* **Local Storage** – Saving cart and wishlist data

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start browsing the website.

## 🎯 Project Purpose

This project was created to practice **front-end web development** and understand how HTML, CSS, and JavaScript can be combined to build a functional e-commerce website.
